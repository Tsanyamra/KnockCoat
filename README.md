# KnockCoat

KnockCoat enables Real-Time, Scalable, and Adaptive network services via a centralized Load-Balancing Gateway Platform.

With KnockCoat, you get a lightweight tool that stays out of your way.

**What you get**

- KnockCoat enables Real-Time, Scalable, and
- Adaptive network services via a
- centralized Load-Balancing Gateway Platform

## Key Features

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/KnockCoat.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

KnockCoat is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
